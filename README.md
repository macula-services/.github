# .github

Default community health files for the `macula-services` repositories.

`FUNDING.yml` renders the Sponsor button on every repository under `macula-services`
that has no FUNDING.yml of its own. It points at https://github.com/sponsors/rgfaber.

Note: the file alone is not enough. Each repository also needs its Sponsorships
feature switch enabled (Settings -> General -> Features -> Sponsorships), which
defaults to OFF on newly created repositories.
